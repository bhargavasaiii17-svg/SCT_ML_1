# House Price Prediction using Linear Regression

## 📌 Project Overview

This project aims to predict house prices using Machine Learning. A Linear Regression model was developed using important house features such as living area, number of bedrooms, and number of bathrooms.

The project demonstrates the complete machine learning workflow including data preprocessing, model training, evaluation, prediction, and visualization.

---

## 🎯 Objective

To build a machine learning model that can accurately predict house prices based on house characteristics.

---

## 📂 Dataset

**Dataset:** House Prices - Advanced Regression Techniques

The dataset contains various features related to residential homes and their sale prices.

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* Google Colab

---

## 📊 Features Used

* GrLivArea (Above Ground Living Area)
* BedroomAbvGr (Number of Bedrooms)
* FullBath (Number of Bathrooms)

### Target Variable

* SalePrice

---

## 🤖 Machine Learning Algorithm

**Linear Regression**

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values.

---

## 📈 Model Evaluation

### Results

* R² Score: **0.6341**
* Mean Absolute Error (MAE): **35788.06**

The model successfully learned the relationship between house features and sale prices and achieved reasonable prediction performance.

---

## 🏠 Sample Prediction

Input:

* Living Area: 2000 sq.ft
* Bedrooms: 3
* Bathrooms: 2

Predicted House Price:

**$240,377.51**
